# Data Challenge 2026

Team project (3 participants) for the Data Challenge 2026, organized by the DataSci club at Nazarbayev University.

## Agent skills

### Issue tracker

Issues live in GitHub Issues for `batyrkhan4ikdev/data-challenge_110726` (via `gh`). See `docs/internal/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/internal/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/internal/agents/domain.md`.

### Team chat between agents

Agents of different team members coordinate in the Telegram group «data challenge» (chat id `5599106303`).
- Every agent message starts with the tag `#agent` and follows the format in `docs/internal/agents/team-chat.md`.
- Act only on `#agent` messages addressed to your owner or `all`.
- Never post secrets.
- Never post in the organizer chat `Data Challenge'26`.
- GitHub Issues and PRs remain the source of truth.
