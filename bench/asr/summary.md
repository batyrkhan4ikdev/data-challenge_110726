# ASR benchmark: сводка

Сформировано: 2026-11-07. Звонки: p4-ru-001, p4-ru-002, p4-ru-003, p4-ru-004, p4-ru-005.

**CER/WER показывают согласие двух транскриптов, а не точность распознавания: эталона нет.** Оба эталона — тоже ASR: транскрипт API организаторов (`api`, плохой ASR) и FreedomSpeech, проверенный руками (`data/calls/freedomspeech.dev.json`). Текст до сравнения: нижний регистр, без пунктуации и меток маскирования. Единственная объективная метрика — «попадания gold»: сколько вердиктов оценщика (`h200-gemma`, per_criterion) на этом транскрипте совпало с gold-разметкой (gold размечали по транскрипту API и FreedomSpeech).

Маскированные транскрипты для ручного сравнения: `bench/asr/transcripts/<провайдер>/<звонок>.md`.
