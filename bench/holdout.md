# Holdout-гейт (#47)

Разбиение: `bench/gold/holdout.json`, создаётся командой `python scripts/holdout_gate.py --write-split`. 60 DEV-чатов (RU 30 / EN 15 / KZ 15) стратифицированы по языку, перемешаны с seed 20261108 и разрезаны на 45 для подбора (RU 23 / EN 11 / KZ 11) и 15 holdout (RU 7 / EN 4 / KZ 4). Эталонная разметка — текущий `load_gold()` (строки людей поверх консенсуса LLM). Звонки исключены.

```
python scripts/holdout_gate.py --before <run> --after <run>   # exit 1 = overfit flag
```

Флаг переобучения: взвешенное совпадение (WA) на подборе выросло, на holdout — нет.

## Результат на закоммиченных прогонах (все `h200-gemma · per_criterion · k=1`)

| изменение (`docs/internal/research/benchmark-phase1.md`) | WA на подборе | WA на holdout | флаг |
|---|---|---|---|
| правило C7 -> + правило области C3 (`195213` -> `204453`, закоммичено в `bench/baselines/`) | 0.911 -> 0.923 (+1.2 pp) | 0.941 -> 0.951 (+1.0 pp) | нет |
| C7 с фразами из DEV -> C7 с перефразировками (проверка утечки, `195213` -> `203620`) | 0.911 -> 0.907 | 0.941 -> 0.934 | нет (оба упали) |
| режим per_criterion -> режим single (`204453` -> `030915`; не изменение заметок, для справки) | 0.923 -> 0.910 | 0.951 -> 0.970 | нет |

Изменение C3 сдвигает обе части в одну сторону, поэтому гейт его не флагует, но оба доверительных интервала включают 0: это тоже не свидетельство реального прироста. Флаг срабатывает всегда, когда на подборе есть улучшение, а на holdout нет (включая ничью), поэтому на 15 диалогах holdout, где bootstrap 95% ДИ шириной около ±3 pp, это повод посмотреть, а не вердикт; кроме того, диалоги holdout видели при написании прежних заметок, так что эти прогоны in-sample. Гейт рассчитан на следующую правку заметок, при которой чаты holdout читать при её написании нельзя.
