# Транскрипты звонков FreedomSpeech

5 DEV-звонков, транскрибированных FreedomSpeech ASR (`POST https://api.freedomspeech.kz/v1/audio/transcriptions`, `response_format=diarized_json`) по аудио из `audio_url`. Сам сервис распознаёт текст заметно точнее ASR фикстуры: имена операторов, приветствие и суммы слышны.

- `p4-ru-00N.md` — для людей: `[i] мм:сс · роль: текст`, время от начала записи.
- `data/calls/freedomspeech.dev.json` — те же записи в формате ответа API организаторов (`data.records[]`), читается `server.dataset.normalize_response`.

Как собрано:

- Роли (оператор, клиент, бот) проставлены по смыслу поверх номеров говорящих FreedomSpeech. Реплики коллег оператора во время удержания помечены как `operator`, как в фикстуре.
- Системные события (запись начата/приостановлена, удержание, завершение) взяты из фикстуры. Время звука переведено в её шкалу с учётом паузы записи.
- Данные клиентов и имена сотрудников заменены масками фикстуры: `[Имя скрыто]`, `[Персональные данные скрыты]`, `[Данные идентификации скрыты]`. Это ФИО, ИИН, адреса, OTP-коды, номера поручений, город клиента. Перед коммитом файлы проверены скриптом и отдельным агентом.
- Номера реплик `[N]` здесь свои и не совпадают с `transcripts/<id>.md`. Ручную разметку звонков по этим транскриптам храните отдельно от gold по фикстуре.
- Основа — живой прогон FreedomSpeech (`bench/asr/freedomspeech-live.dev.json`, он остаётся как есть). Три человека прослушали все 5 звонков и оценили каждую реплику (ужас / норм / идеально) с заметками: 200 из 230 реплик, неоценёнными остались в основном системные события. По заметкам исправлены слова, роли, пунктуация; склеенные реплики разных людей разделены, названные в заметке пропущенные слова добавлены. Реплика без заметки оставлена как распознана; то, что без звука восстановить нельзя (неназванные ответы IVR, точный порядок слов при одновременной речи), не придумано.
- p4-ru-002: разговор оператора с трейдером на удержании (один блок в выдаче FreedomSpeech) разбит на реплики по границам и времени транскрипта организаторов; обе стороны `operator`. Вступление до старта записи (3 реплики) взято из предыдущего прогона FreedomSpeech того же аудио.
- Этот файл — эталон `cer_vs_freedomspeech` в `bench/asr/summary.md`.

Сырые ответы FreedomSpeech и аудио в репозиторий не кладём: в них данные клиентов открытым текстом.
