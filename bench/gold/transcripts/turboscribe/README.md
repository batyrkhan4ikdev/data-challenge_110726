# Транскрипты звонков TurboScribe

Batyrkhantzy111 транскрибировал 5 DEV-звонков в TurboScribe по аудио из `audio_url` с разделением на 3 говорящих. Точность заметно выше ASR из `tests/fixtures/dev.json`.

Сырые транскрипты в репозиторий не кладём: в них открытым текстом записаны ФИО, адреса, ИИН и OTP-коды клиентов. Фикстура организаторов эти данные маскирует. Файлы хранятся только у разметчиков, локально.

Как размечать звонки по этим транскриптам:

- Читайте локальный транскрипт TurboScribe, а не ASR фикстуры. В нём меньше искажений: имя оператора, приветствие, суммы, реплики трейдера на удержании.
- Номера реплик `[N]` для `gold_evidence` берите по `bench/gold/transcripts/<id>.md`. TurboScribe делит текст на реплики по-другому.
- Номера «Говорящий 1/2/3» назначены автоматически и в разных файлах означают разных людей. Роль определяйте по смыслу.
- Запись TurboScribe может начинаться или заканчиваться не там, где транскрипт фикстуры.
- Оценщик контроля по-прежнему получает транскрипт из API (#2825). Транскрипты TurboScribe нужны только людям.
