# Калибровка: 5 DEV-диалогов, 4 способа разметки

Источник `labels.consensus.csv`. Индексы реплик совпадают с `bench/gold/transcripts/<id>.md`.

## Как размечали

- Диалоги: `p1-ru-007`, `p1-ru-017`, `p1-en-011`, `p1-kz-010`, `p4-ru-005` (случайно, seed 2026, см. `selection.json`).
- Инструкция для всех разметчиков: `instructions.md` (формулировки официального чек-листа и #2343 для звонков).
- 12 агентов, 4 способа, без доступа к чужим результатам и ручной разметке (`runs/`):
  - `all-5_gpt6-astra-xhigh.csv`: GPT-6 Astra xhigh, все 5 диалогов в одном контексте;
  - `all-5_opus-5.5-xhigh.csv`: Claude Opus 5.5 xhigh, все 5 в одном контексте;
  - `<n>-<id>_gpt6-astra.csv`: GPT-6 Astra, отдельный агент на каждый диалог;
  - `<n>-<id>_opus-5.5.csv`: Claude Opus 5.5, отдельный агент на каждый диалог.
- Ручная разметка Batyrkhantzy111 есть только для `p1-ru-007` (`human.p1-ru-007.csv`).
- Файлы в `runs/` сохранены как их записали агенты. В `1-p1-ru-007_opus-5.5.csv` и `5-p4-ru-005_opus-5.5.csv` id диалога записан с номером (`1-p1-ru-007`); при сравнении номер отброшен.
- Разметчики видели диалоги в виде `[i] мм:сс · роль: текст`; индексы `[i]` те же, что в `bench/gold/transcripts/`.

## Согласие

Все 4 способа совпали в 28 из 40 оценок. Попарно 31–37 из 40. Почти все расхождения в c07 (Завершение).
По `p1-ru-007` ручная оценка совпала с итоговой во всех 8 критериях.

## Как решены расхождения

- Единогласные оценки приняты как есть.
- c07: по ответу организаторов #2814 одно прощание без итога или предложения помощи — «Нет».
- c03 в звонке: командное правило из #2978 — оператор запросил данные для идентификации, клиент их назвал.
- Остальное: большинство голосов, при равенстве — решение по тексту чек-листа. Голоса и причина записаны в `note` каждой строки.
