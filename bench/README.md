# Бенчмарк: как мы выбирали стек

Здесь лежат эксперименты, по которым выбраны модель, режим оценки и ASR, и данные к ним. Каждое число ниже взято из указанного файла. Обзор проекта: [README](../README.md), техническая документация: [`docs/reference.md`](../docs/reference.md).

Метрика: **взвешенное совпадение** (WA) с эталонной разметкой по критериям, веса берутся из чек-листа. Кроме него в сводках `summary.md` есть MAE итога и смещение итога. Если не сказано иное, цифры даны по 60 чатам из 65 DEV-диалогов: контрольный набор состоит только из чатов (#2978).

## Как мы выбирали стек

Сравнивали два режима (`single`: один вызов на все критерии; `per_criterion`: один вызов на критерий) и модели трёх видов: свои на H200 (Gemma 4 31B, Muse-Glimmer-30B, `h200-gptoss`, `h200-kz`), облачные (Claude Sonnet 5.5, GPT-6 Luna, AlemLLM и передовые модели через OpenRouter) и открытые веса (Qwen3.8-27B, Qwen3.8-Flash-Next, DeepSeek-V4.1-Flash, Kimi-K2.6). Профили описаны в `config/profiles.toml`. Полные таблицы всех раундов: [`docs/internal/research/benchmark-phase1.md`](../docs/internal/research/benchmark-phase1.md).

**Раунд 3, итоговые заметки чек-листа** (правила C3, C7, C8; `benchmark-phase1.md`, раздел «Round 3»):

| Прогон | WA | Совпавших вердиктов из 480 |
|---|---|---|
| **`h200-gemma` · `per_criterion`**, 3 прогона | **0.929** (0.927–0.930) | 450–451 |
| `h200-gemma` · `per_criterion` · k=3 (t=0.7, медиана) | 0.924 | 449 |
| Ансамбль gemma + Qwen3.8-27B + Qwen3.8-Flash-Next, 12 офлайн-комбинаций | 0.928 (0.918–0.940) | 452 |
| Ансамбль, вживую (2 прогона) | 0.924, 0.926 | 449, 451 |
| Qwen3.8-27B · `single` | 0.901–0.919 | 437–446 |
| Qwen3.8-Flash-Next · `single` | 0.908–0.915 | 444–446 |
| DeepSeek-V4.1-Flash · `single` | 0.896 | 439 |
| Kimi-K2.6 · `single` | 0.851 | 422 |

**Передовые модели через OpenRouter**, режим `single`, парное сравнение на тех же чатах (`benchmark-phase1.md`, раздел «Frontier models via OpenRouter»). Часть запросов отклонена с HTTP 402 из-за резервирования кредита, поэтому у каждой модели своё число оценённых чатов, а gemma считалась на тех же диалогах:

| Модель | Оценено чатов | Совпадения модели | Совпадения gemma на тех же чатах |
|---|---|---|---|
| Gemini 3.8 Flash | 49 | 363/392 (0.926) | 367/392 (0.936) |
| Gemini 4 Argon | 33 | 243/264 (0.920) | 249/264 (0.943) |
| Grok 4.7 | 36 | 264/288 (0.917) | 267/288 (0.927) |
| DeepSeek-V4-Pro | 50 | 360/400 (0.900) | 371/400 (0.927) |

**Режим.** На финальных заметках `per_criterion` даёт 0.936 (`bench/results/20261107-213204`) и 0.931 (`20261107-213616`) по чатам; `single` на тех же заметках — 0.925 (`20261108-030915`), но примерно в 1.8 раза быстрее: 16.1 с на диалог против 27.7–31.8 с (`benchmark-phase1.md`, раздел «Gemma single vs per_criterion»). Заметки подбирались в режиме `per_criterion`, поэтому он остаётся по умолчанию.

**Решение:** `h200-gemma` · `per_criterion` · `k=1`, температура 0, с облачным запасом Claude Sonnet 5.5 → GPT-6 Luna → h200-glimmer.
- Лучший облачный результат на раунде с полной разметкой (Luna, `single`) на 3.4 п.п. ниже: 0.884 против 0.918 (`benchmark-phase1.md`, раздел «Phase 2 on the full consensus gold»). Правило выбора: своя модель, если облачная не лучше более чем на 5 п.п.
- Ансамбль сравнялся с gemma по WA (0.928 против 0.929), но требует трёх эндпоинтов и мягче по смещению итога (+2.3 против −1.1).
- Gemma воспроизводит 99.6% вердиктов между прогонами (477–479 из 480). Два полных прогона DEV на итоговых заметках совпадают по 514 из 520 вердиктов (98.8%, `docs/reference.md`, раздел «Воспроизводимость»).
- Голосование k=3 и режим размышлений не помогли.

**Стоимость одной оценки** (`docs/internal/research/llm-candidates.md`, `benchmark-phase1.md`, `summary.md` прогонов):

| Вариант | Цена |
|---|---|
| Свой H200, `per_criterion` | ≈ $0.003 (`bench/results/20261107-213204/summary.md`) |
| Свой H200, `single` | ≈ $0.001 (`bench/results/20261108-030915/summary.md`) |
| Claude Sonnet 5.5, `single`, $2 / $10 за 1M токенов | ≈ $0.024 |
| GPT-6 Luna, `single`, $0.10 / $0.50 за 1M токенов | ≈ $0.001 |

H200 посчитан по $5.35 за GPU-час: медиана on-demand цен Vast, RunPod, Nebius и CoreWeave на 2026-11 (`llm-candidates.md`, раздел 1). Формула: `$/h × GPU-секунды ÷ параллелизм ÷ 3600`.

## Разметка (gold)

Эталона организаторов нет, поэтому эталонная разметка собрана командой: [`bench/gold/README.md`](gold/README.md).

- **Консенсус LLM** (`bench/gold/labels.consensus.csv`, 65 DEV-диалогов): 4 слепые разметки на диалог, GPT-6 Astra и Claude Opus 5.5 на xhigh, пачками по 10 диалогов и по одному. В раунде 2 (60 диалогов, 480 оценок) все 4 способа совпали в 422 оценках, большинство в 28, ничья 2:2 в 30 (`bench/gold/calibration/round2/README.md`). Раунд 1 — 5 диалогов с ручной проверкой `p1-ru-007` (`bench/gold/calibration/README.md`).
- **Ручные строки** (`bench/gold/labels.Batyrkhantzy111.arbitration.csv`): 20 строк, 12 спорных вердиктов чатов и ручная разметка `p1-ru-007`. Они перекрывают консенсус построчно; `python -m bench.run --set gold --gold human` использует только их.
- **Сверка с чужой разметкой DEV** (`bench/gold/README.md`, раздел «Сверка с разметкой других команд»): 8 публичных наборов других команд совпадают с нашей эталонной разметкой на 83.9–99.3% клеток чатов. На звонках внешние метки есть у двух авторов: 11 из 16 клеток (68.8%) и 19 из 24 (79.2%).
- `bench/arbitration_queue.py` строит очередь клеток для ручного арбитража: `bench/gold/arbitration_queue.csv`.

## Распознавание речи (ASR)

Сравнивали 9 провайдеров на 5 DEV-звонках (`bench/asr/summary.md`). CER и WER показывают согласие двух транскриптов, а не точность: оба эталона тоже ASR (транскрипт API организаторов и проверенный вручную FreedomSpeech). Объективная метрика — попадания вердиктов оценщика в эталонную разметку на каждом транскрипте, из 40 ячеек на источник.

| Источник | Диаризация | CER относительно FreedomSpeech | Попадания в эталон |
|---|---|---|---|
| T-one + pyannote (`h200-t-one`) | да | 0.118 | 29/40 |
| GigaAM-v3 + pyannote (`h200-gigaam-v3`) | да | 0.126 | 27/40 |
| Gemini 3.5 Transcribe (`or-gemini-transcribe`) | да | 0.145 | 28/40 |
| KuSpeech multilingual (`kuspeech`) | нет | 0.158 | 29/40 |
| Whisper large-v3 · 2 (H200) | нет | 0.203 | 28/40 |
| WhisperX + pyannote (`h200-whisperx`) | да | 0.271 | 25/40 |
| Whisper large-v3 (H200) | нет | 0.309 | 25/40 |
| Whisper large-v3 turbo (H200) | нет | 0.370 | 27/40 |
| FreedomSpeech (`freedomspeech`) | да | эталон | 27/40 |
| Транскрипт API организаторов | — | — | 26/40 |

Повторная оценка того же транскрипта FreedomSpeech даёт 1 смену вердикта из 40 ячеек (`bench/asr/noise-floor.md`), поэтому разница в одну-две ячейки не ранжирует источники.

Другие материалы:
- [`bench/asr/kazakh.md`](asr/kazakh.md): один казахский звонок, который датасет помечает как RU.
- [`bench/asr/synthetic.md`](asr/synthetic.md): 40 синтетических звонков (RU 24, KZ 8, EN 8) с точным эталоном-сценарием; судья на точном тексте попал в замысел в 223 из 270 ячеек.
- [`bench/asr/noise-floor.md`](asr/noise-floor.md): флипы вердиктов и MAE итога на каждом источнике.

## Синтетика и holdout

- **Синтетические edge-кейсы** ([`bench/synthetic.md`](synthetic.md), #49): 60 родительских диалогов, 177 правок по шести трансформациям, судья `h200-gemma` · `per_criterion`. Ожидаемый вердикт по целевому критерию получен в 57/57 для `c01_drop_greeting`, 8/8 для `c07_strip_farewell`, 49/49 для `c08_offer_offsite_transfer` и 49/49 для `c08_insult`. Для `c07_drop_closing_turn` вердикт получен в 4 случаях из 9, ожидаемый — в 2; для `c03_drop_identification` — 1 из 4.
- **Holdout-гейт** ([`bench/holdout.md`](holdout.md), #47): 60 DEV-чатов разделены на 45 для подбора и 15 holdout, стратификация по языку, seed 20261108. Гейт помечает изменение заметок, если WA на подборе вырос, а на holdout нет. На закоммиченных прогонах флагов нет: правило C3 дало 0.911 → 0.923 на подборе и 0.941 → 0.951 на holdout (`195213` → `204453`); проверка утечки фраз C7 дала 0.911 → 0.907 и 0.941 → 0.934 (`195213` → `203620`).

## Как воспроизвести

```bash
python -m bench.run --profiles h200-gemma,aigw-sonnet --mode single --k 1 --set smoke|gold [--gold human]
python -m bench.run --profiles h200-gemma --mode per_criterion --k 1 --set gold   # настройка контрольного прогона
python scripts/regress_gate.py --baseline bench/baselines/20261107-195213 --candidate bench/baselines/20261107-204453
python scripts/holdout_gate.py --before <run> --after <run>
python -m bench.asr [--providers aigw-whisper,kuspeech,...] [--calls p4-ru-001,...] [--reuse-raw] [--no-score]
python -m bench.synthetic generate
```

Прогоны на моделях требуют доступа к эндпоинтам из `.env` (`H200_*`, `AIGW_*`, см. [`docs/reference.md`](../docs/reference.md)). `regress_gate.py` на закоммиченных прогонах работает без сети. Подробности про гейты, ASR-бенчмарк и синтетические звонки: [`docs/reference.md`](../docs/reference.md), разделы «Бенчмарк и эталонная разметка» и «Транскрипты звонков и ASR».
