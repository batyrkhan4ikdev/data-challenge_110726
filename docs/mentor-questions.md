# Questions for Freedom Broker

These are posted by a team member in the "Freedom Broker" topic or asked at the mentor session. Agents never post them. Answers go to `docs/organizer-answers.md`.

1. **Как сравнивается с эталоном?** Сверяете ответы по каждому критерию (Да/Нет/N/A/ступень), итоговый балл или и то и другое? Учитывается ли флаг грубой ошибки?
2. **Пример расчёта.** Можно ли получить один размеченный диалог с ответами по критериям и итогом, где есть N/A? Хотим сверить перераспределение веса и округление (мы используем округление половины вверх: 50,625 → 50,63).
3. **Состав контрольного набора.** Будут ли среди 10 транскриптов звонки? Если да, эталон для звонков составлен по адаптированному критерию №6 из сообщения #2343?
4. **Замена критерия на проверке.** Новый критерий заменяет один из восьми с тем же весом или веса тоже меняются? Нужно ли пересчитать уже оценённые контрольные диалоги по новому чек-листу?
5. **Формат сдачи результатов.** Как передать оценки контрольного набора для сравнения с эталоном: показ в интерфейсе, файл (какой формат) или ссылка на развёрнутый сервис?
6. **Критерий №1 при участии бота.** Если первым клиенту ответил бот, а оператор подключился позже, «первый ответ» — это первая реплика оператора?
