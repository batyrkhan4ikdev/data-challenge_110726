# Internal notes

Working notes of the team, kept in English or Russian as written. They are not part of the submission documentation (see the root `README.md`).

- `organizer-answers.md`: organizers' answers and announcements the checklist rules rely on.
- `mentor-questions.md`: questions prepared for the mentor session.
- `research/`: model, ASR, D365 and cost research, including `benchmark-phase1.md` (all benchmark rounds).
- `redesign/`: the UI redesign brief, proposals and the `after/` screenshots.
- `agents/`: issue tracker, triage labels, domain-doc layout and team-chat rules for coding agents (linked from the root `AGENTS.md`).

The redesign `before/` and `baseline/` screenshots, the capture script and the brand copies were removed from the working tree; links to them in `redesign/` are historical and resolve through git history.
