# FreedomSpeech: отчёт и мини-план экстра-фичи

FreedomSpeech (https://freedomspeech.kz) — сервис ASR/TTS для казахского, русского и английского языков. Документация: https://freedomspeech.kz/docs/. Ключи выдаёт console.freedomspeech.kz.

## Что проверено на 5 DEV-звонках

| Что | Результат |
|---|---|
| STT `POST https://api.freedomspeech.kz/v1/audio/transcriptions`, `response_format=diarized_json` | 200 на всех 5 звонках, 7–13 с на звонок длиной 5–11 минут |
| Async `POST https://freedomspeech.kz/v1/async/transcriptions` | job в статусе `failed`: `All ASR servers failed … HTTP 404`. Не использовать |
| Без заголовка `User-Agent` браузера | Cloudflare отвечает `403 error code: 1010`. Нужен браузерный `User-Agent` |
| Диаризация | Тайм-коды есть только в `text` в виде `[speaker-N \| start-end] …`. У `segments` поля `start`/`end` равны 0. `known_speaker_names[]` назначает имена только первым двум говорящим, остальные получают метки C, D… |
| Качество на слух | Лучше ASR фикстуры: распознаны имена операторов, приветствия, казахское IVR, суммы (25 $ / 2 %). На неразборчивой речи во время удержания местами мусор. WER не измерялся |
| Аудио | `audio_url` из API организаторов отдаёт HTML-плеер. mp3 лежит в `<source src>` (подписанная ссылка Dynamics, живёт 1 час) |

Результат лежит в `data/calls/freedomspeech.dev.json` (формат ответа API организаторов, проходит `normalize_response`) и в `bench/gold/transcripts/freedomspeech/*.md`. Роли проставлены по смыслу, системные события взяты из фикстуры, персональные данные замаскированы. Подробности — в README той папки.

Ключ: сейчас используем демо-ключ веб-фронта FreedomSpeech. Перед стоп-кодом Батырхан заменит его на новый демо-ключ. Ключ живёт только в `.env` как `FREEDOMSPEECH_API_KEY`, в репозиторий не коммитим.

## Решения

- **TurboScribe не используем.** Его транскрипты и производные удалены. Для звонков остаются транскрипт API организаторов и FreedomSpeech.
- **Fine-tune (если будет) — только на транскриптах в формате API организаторов**, то есть на чатах. Контроль — только чаты (#2978), звонки нужны только для интерфейса (#3075). ASR-транскрипты в обучение не берём. Окончательно решает агент Арына.
- **Оценщик контрольного прогона** по-прежнему получает транскрипт из API (#2825). FreedomSpeech — дополнительная функция интерфейса для звонков.

## Мини-план экстра-фичи (владелец — агент Арына, контракты меняет интегратор)

1. **Клиент ASR** — `server/asr/freedomspeech.py`. `transcribe(mp3: bytes) -> list[Segment]`: синхронный endpoint, `X-API-Key` из `FREEDOMSPEECH_API_KEY`, браузерный `User-Agent`, разбор `[speaker-N | s-e]` из `text`.
2. **Загрузка звука.** По `audio_url` получить HTML, взять `<source src>`, скачать mp3. Ссылка живёт час, поэтому получать её непосредственно перед распознаванием.
3. **Сборка транскрипта.** Назначить роли: говорящие IVR — `bot`, говорящий с «Freedom Broker… меня зовут» после перевода — `operator`, остальные — `client`. Добавить системные события из исходной записи и перевести время с учётом паузы записи. Обязательно маскировать ПДн (ФИО, ИИН, адрес, OTP, номера поручений) теми же метками, что у фикстуры. Сырой ответ не сохранять.
4. **API и UI.** Транскрипт звонка хранится в двух вариантах: «API организаторов» и «FreedomSpeech», в карточке звонка их можно переключать. Оценка запускается на выбранном варианте, в `Evaluation` записывается `transcript_source`. Новые маршруты: `POST /api/conversations/{cid}/transcribe?provider=freedomspeech`. Потоковый WS `wss://api.freedomspeech.kz/ws/asr` (PCM16 16 кГц mono) — для демо «транскрипт на лету».
5. **TTS на сайте: два провайдера.** `POST /api/tts?provider=freedomspeech|<второй>` и в интерфейсе кнопка «Озвучить» с выбором провайдера. FreedomSpeech: `POST https://api.freedomspeech.kz/v1/audio/speech`, голоса `tomiris`/`taymas`/каталог, WAV 24 кГц. Вторую модель подбирает и тестирует Арын.
6. **Бенчмарк ASR (агент Арына).** Сравнить FreedomSpeech и готовые открытые и облачные STT-модели на 5 DEV-звонках: точность (WER/CER относительно эталона, если он будет), диаризация, имена, казахская речь, скорость. Готовые таблицы передать Батырхану — сравнение он делает сам.

Риски: демо-ключ чужой, а лимиты неизвестны. Cloudflare может снова заблокировать запросы. Сырые ответы содержат ПДн — маскирование обязательно до записи на диск и в логи.
